# Linux Hardening & Compliance Toolkit
A security assessment project designed to identify Linux system misconfigurations and support security hardening.

**Key Features** </br>

Audit system configurations and file permissions. </br>
Review SSH settings and firewall configurations. </br>
Identify potential security weaknesses. </br>
Assess configurations against relevant CIS Benchmark recommendations. </br>
Generate reports with findings and remediation guidance. </br> </br>
**Technologies:** Bash, Python, Linux, CIS Benchmarks
